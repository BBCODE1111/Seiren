# Seiren 透明介面與中英切換

2026-11-03。依使用者要求保留原本希臘美術與品牌，增加面板透明感，提供繁體中文／英文切換。

## 外觀

參考 Khimaira 的 `dist/odyssey.css` 玻璃層次；保留 Seiren 原有雕塑背景、徽章、字體與綠色音符。`seiren-glass.css` 集中調整透明度，避免多層象牙色面板疊成實色。一般面板約 38% 不透明度，置頂和弦譜約 60%，底部播放列約 72%；浮動選單維持較實的底色以利閱讀。手機另調整透明度與語言按鈕位置，支援減少透明效果的系統偏好。修正標記強拍按鈕原有 44px 固定寬度造成的文字重疊。

## 語言

- 頁首「中／EN」切換；預設繁體中文，偏好記錄在 `seiren-language`，儲存失敗仍可正常切換。
- `i18n-catalog.js` 是本機文案表，涵蓋主介面、旋律設定／編輯、原音變速提示、音型與樂風說明、混音、版本比較、匯出選項及輔助標籤。
- `i18n.js` 只更新文字節點與說明屬性，使用 WeakMap 保留原文；動態新增提示依當前語言更新。只檢查有異動的內容，不重新建立旋律編輯器或播放物件。
- 選項的值、音符、和弦符號、速度、歷史與專案資料不隨語言改變。匯入檔名與音軌名稱保留原名；語言偏好不寫進音樂專案。對沒有明列翻譯的新文案保留原文，後續功能須同步補文案表。
- 外連的既有使用手冊／授權文件仍保留原始內容，本次中英切換範圍是工作介面與內嵌提示。
